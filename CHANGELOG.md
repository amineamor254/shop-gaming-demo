# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-10-24

### Added

- One-page gaming PC storefront with product catalog, PC configurator, blog
  previews, offers, and contact section.
- Cart, checkout, login, and editable legal routes.
- Configurable store identity, products, promo codes, configurator data,
  shipping and tax settings, navigation, and brand color tokens.
- Responsive layout using Next.js App Router, TypeScript, Tailwind CSS, and
  lucide-react.
